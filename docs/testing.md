# 验证与验收

## 自动验证

NUKE Verify 执行文档检查、解决方案构建和核心测试。测试包括同身份显式接管、旧 lease 输入与断开拒绝、跨 issuer 身份边界、断线后归属保留、工作区释放以及并发连接唯一获权。

CI 在 Windows 与 Linux x64 上各自执行 Verify 和 Publish，保存发布产物与 TRX。发布成功作为目标 RID 构建验证，运行能力通过以下环境验收确认。

## 集成验收矩阵

| 领域 | Windows | Linux |
| --- | --- | --- |
| 服务 | SCM 启动、停止、服务账户配置 | systemd 启动、停止、权限与日志 |
| 用户身份 | 登录代理 SID、主目录、锁屏与注销 | UID/GID/附加组、HOME、无人登录时启动 |
| 终端 | ConPTY、PowerShell、全屏 TUI、缩放 | PTY、shell、控制终端、信号与缩放 |
| 进程清理 | 子进程树和句柄释放 | 进程组/cgroup 与文件描述符释放 |
| 文件 | 实际 VirtioFS 驱动与 WinFsp 配置 | 实际挂载配置与宿主 UID/GID |

## 跨平台场景

1. 两个客户端同时连接，确认 host 只有一个有效控制者。
2. 同身份显式接管，旧客户端继续发送输入，确认过期输入被拒绝。
3. 断线后另一身份尝试进入，确认工作区归属保持。
4. 断线期间进程继续产生输出，重连后恢复终端状态。
5. 认证过期或授权撤销后，确认传输关闭和控制权撤销。
6. 全屏编辑器重连，确认光标、颜色、备用屏幕和尺寸一致。
7. 显式终止清理完整进程树后，确认新的身份可以创建工作区。

存储场景细化见[VirtioFS 验收](platforms/storage.md)。每次环境验收记录系统版本、运行用户、依赖版本、配置、执行步骤与实际结果。
