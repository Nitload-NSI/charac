# 用户环境

| 项目 | Windows | Linux |
| --- | --- | --- |
| 账户标识 | SID | UID、GID 与附加组 |
| 登录环境 | OpenSSH 建立目标用户环境，默认 Shell 可配置 | sshd/PAM 建立目标用户环境 |
| 主目录 | 目标账户配置决定 | 目标账户与 PAM 配置决定 |

Server 将经 OIDC 身份提供方认证的身份映射到授权目标与系统账户，再通过 SSH 登录凭据连接。工作区进程由目标 sshd 按系统账户启动；Server 不启动用户 Agent，也不直接切换用户身份。需在目标系统验收环境变量、主目录、工作目录、组权限与登录策略。认证设计见[身份认证](../authentication.md)。
